Data & Ekspor

Alur kerja singkat
  1. Jalankan server lokal: python -m http.server 8000, lalu buka http://localhost:8000/content-manager.html.
  2. Tambah atau edit konten, lalu klik Simpan konten. Perubahan hanya ada di memori halaman ini.
  3. Klik Ekspor Paket Website (.zip). ZIP berisi data/contents.json dan gambar baru di assets/images/.
  4. Ekstrak ZIP ke folder utama proyek (timpa file lama), lalu upload ke GitHub.
  5. Untuk Linkvertise, tempel Alamat halaman download (bagian D) sebagai tujuan akhir.
